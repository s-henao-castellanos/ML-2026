# Multi-Layer-Perceptron classifiers

> Por Daniela Lancheros y Santiago Henao

Se entrena una red neuronal de tipo perceptrón multicapa para clasificar pistas musicales en su género según ciertas features predefinidas.

Se implementa una búsqueda de grilla para arquitectura rectangular, tasa de aprendizaje y tamaño del batch en torch, ejecutada en un entorno de HPC SLURM.

Se implementa una búsqueda aleatorizada de arquitectura mixta, tasa de aprendizaje, tamaño del batch y algoritmo de optimización en Keras.

La reducción de datos y el separado en train, test y validation se realizó de la misma manera en ambos casos.
